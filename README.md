# HireFlow

A recruitment management platform built with .NET 10
using Clean Architecture and CQRS.

## Features

- User Registration & Authentication
- JWT + Refresh Token
- Role-Based Authorization
- Job Management
- Candidate Applications
- Application Status Management
- Interview Management

## Architecture

- Clean Architecture
- CQRS
- MediatR
- Repository Pattern

## Technologies

- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Redis
- RabbitMQ
- MassTransit
- Docker
- Serilog
- FluentValidation
- xUnit

## Testing

- Unit Tests
- Integration Tests
